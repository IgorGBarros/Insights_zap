# Insights Zap

Captura o que tem valor nas conversas de WhatsApp (links, documentos, áudios, ideias),
resume e organiza com agentes de IA numa base de conhecimento pesquisável da empresa.

Construído como uma **vertical do [pgba-boilerplate](https://github.com/IgorGBarros/pgba-boilerplate)**,
reaproveitando a Evolution API, o pipeline de conhecimento (`ingestion`), o harness de IA e
o Design System já existentes.
